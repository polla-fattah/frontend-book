# Practical Companion

These practicals extend the main manuscript without making every chapter a large implementation manual. They are intentionally separate from the chapter prose so readers can choose a guided exercise, an advanced extension, or a reference implementation later.

Each practical should be completed in a small Vite + TypeScript project unless the brief explicitly calls for a server, browser-only page, or test runner. Use current browser support checks for newer APIs.
